# Контрольная точка инфраструктуры рабочей среды — 2026-08-27 v2

Предыдущая публичная контрольная точка: `docs/WORKSPACE_RUNTIME_CHECKPOINT_2026-08-27.md`.
English version: `docs/WORKSPACE_RUNTIME_CHECKPOINT_2026-08-27-v2.en.md`.

## Область

Документ фиксирует только переносимые и обезличенные факты о конфигурации
репозитория, валидаторах, hooks и политике публикации.

## Изменения

- Добавлен fail-closed валидатор локального `.env`: он проверяет права доступа,
  дубли переменных, согласованность `target/path` и read-only guards, не выводя
  значения секретов.
- `SessionStart` сначала выполняет проверку env-контракта, затем Reality
  Reconciliation и неблокирующе планирует обновление Graph V2.
- Hygiene-проверка запрещает попадание в Git любых virtualenv с префиксом
  `.venv` и артефактов code-index.
- Добавлены обезличенные unit-тесты валидатора и тест порядка проверок hook.
- Правила `.gitignore` сохраняют защиту локальных env/IDE/agent-файлов и
  диагностических артефактов.

## Проверки

- `py_compile` скриптов инфраструктуры;
- unit-тесты валидатора и hooks;
- hygiene-проверка tracked-артефактов;
- `diff --check` и штатные Git hooks;
- Graph V2 deep-check.

## Публичная граница

В публикацию входят только инфраструктурные скрипты, правила, hooks, тесты и
данная документация. Локальные `.env`, ключи, пароли, RAG/
`knowledge_base.json`, Graph/runtime-индексы, базы данных, BSL/SQL-исходники,
логи и build-артефакты исключены.

## Ограничения доказательности

Публичная контрольная точка не доказывает доступность или корректность
удалённой 1С-базы, HTTP-публикации или физической SQL-схемы. Она фиксирует
только статически проверяемые инструменты и политики локальной рабочей среды.
