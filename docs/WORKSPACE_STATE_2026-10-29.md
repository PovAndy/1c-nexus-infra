# Состояние рабочей среды: версия 1.0.1

## Назначение и границы снимка

Этот документ фиксирует переносимое состояние инфраструктурного репозитория
`1c-nexus-infra` на **2026-10-29**. Он предназначен для воспроизводимой
настройки локальной среды разработки 1С и не является снимком базы данных,
развёртывания или содержимого зависимых рабочих проектов.

В репозиторий не включаются секреты, локальные `.env`-файлы, токены,
runtime-кэши, логи, виртуальные окружения, артефакты Graph V2 и исходники
обработок EPF. Эти данные либо локальны, либо требуют отдельного
контролируемого процесса передачи.

## Эксплуатационный порядок

1. Клонировать репозиторий и установить зависимости в отдельное окружение
   Python, не добавляя его в Git.
2. Скопировать только пример конфигурации `.env.example` в локальный
   игнорируемый файл при необходимости; значения ключей не публиковать.
3. Проверить `python3 scripts/validate_prompt_contracts.py` и
   `python3 scripts/check_workspace_hygiene.py`.
4. Выполнять RAG pre-flight и целевую навигацию Graph V2 до широкого поиска
   исходников.
5. Для изменений использовать точечный Git staging, проверку diff и скан
   секретов. Данные баз 1С изменять только через разрешённый прикладной поток.

## Известные ограничения

- Локальный снимок состояния не заменяет проверку фактических версий клиента,
  провайдера моделей и удалённых сервисов при запуске.
- `tool_output_token_limit` и правила prompt-контракта ограничивают локальный
  процесс, но не являются доказательством экономии токенов или поведения
  удалённой модели.
- Для запуска тестов нужен интерпретатор с установленными зависимостями из
  `pyproject.toml`; системный Python на дату снимка их не содержит.
