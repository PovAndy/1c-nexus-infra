# Контрольная точка инфраструктуры рабочей среды — 2026-08-27

## Область

Документ фиксирует только инструменты и правила рабочей среды `epf1129`.
Исходники 1С/BSL, SQL, базы данных, дампы, производственные данные, логи,
временные файлы, индексы, виртуальные окружения и секреты в контрольную точку
не входят.

## Сохранённые нововведения

- Codex hooks зарегистрированы в активном конфигурационном слое и вызывают
  единый stdin-JSON диспетчер `scripts/run_hook.py`.
- Pre-commit Graph V2 использует неблокирующую проверку `flock -n`: при занятом
  состоянии выполняется быстрый digest-контроль, без ожидания перестройки.
- `scripts/reconcile_reality.py` на SessionStart сверяет документированный
  handover, SHA-256 `build/compiled.epf`, активную цель и Git-baseline.
- Навыки `grill-me`, `unlazy` и `task-observer` используют компактный
  agentskills.io-манифест с явными правилами запуска и неприменения; каталоги
  `references/` загружаются только при необходимости.
- `AGENTS.md` содержит отдельный GPT-5.6 operating contract с уровнями
  Read-Only, Draft-Only и Action-Allowed после неизменного
  `OMVL_STATIC_PREFIX_V1`.
- RAG lifecycle изменяется только через `kb_manager.py` с блокировкой и не
  переводится в `success` без подтверждения человека.

маскируется под PASS.
