# Наблюдение без самовольных изменений

Сопоставь только факты текущей задачи: что было исправлено пользователем, какой контроль не сработал, какое правило могло бы предотвратить повтор. Сформируй одну компактную гипотезу с наблюдаемым триггером, областью применения и риском ложного срабатывания.

Не записывай приватный контекст, персональные данные, ключи, сырые журналы или содержимое баз. Не меняй `SKILL.md`, `.clinerules`, RAG или код без явного поручения. Сохраняй предложение в локальном временном артефакте только если это прямо запрошено; применение требует отдельного подтверждения человека. Шаблон минимального наблюдения находится в `references/observation-contract.md` и не нужен при обычном запуске навыка.
