# Каталог уточняющих вопросов

Используй только один вопрос на каждую реальную неопределенность: тип и обработка `NULL`, серверный/клиентский контекст, транзакционные границы, время жизни временных таблиц, источник доказательств метаданных. Не превращай каталог в анкету и не предлагай BSL-код до получения ответов.
