# Карточка локальной интеграции навыка: `fuck-my-shit-mountain`

## Назначение

Навык выполняет доказуемый аудит изменений рабочей среды `epf1129` по режимам `stability`, `data-integrity` и `testing-authenticity`. Отчет формируется в `temp/audit_report.html` и включен в предохранитель сборки `compile.win.ps1` и `compile.sh`.

## Локальная адаптация

- Первичный источник: `https://github.com/XiNian-dada/Fuck_My_Shit_Mountain`, коммит `fc0ccc2c199e1edabdef26be791eeed52996eb7a`.
- Локальный путь навыка: `.agents/skills/fuck-my-shit-mountain/`.
- Перед аудитом обязательно обеспечивается актуальность Graph V2; его полный JSON не загружается в контекст.
- Область ограничена только выводом `git diff --name-only`; runtime- и build-артефакты исключаются. Полный аудит репозитория запрещен.
- Самодостаточный HTML-отчет проверяется штатным `report_lint.py` навыка.

## Контракт High Severity

- При первом подтвержденном High Severity создается RAG-запись `under_review` через единственный writer `kb_manager.py`.
- После повторного чистого аудита та же RAG-запись переводится в `unstable`; дубли для неизменной области не создаются.
- Источники `x1_XX` неизменяемы: подтвержденная изменяющая операция рядом с таким алиасом блокирует сборку.

## Ограничения

- Оцениваются только разрешенные измененные файлы; отчет не является утверждением о качестве всего репозитория.
- Секреты, API-ключи и содержимое `.env` не включаются в отчет.
- Для корректной работы обязательны `kb_manager.py`, `report_lint.py` и актуальный Graph V2.
